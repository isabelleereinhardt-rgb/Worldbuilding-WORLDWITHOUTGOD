## 🎴 Mad Max: Wasteland Brawl (Roblox game)

This repo also contains the full source for the Roblox game **Mad Max: Wasteland Brawl**
— a 16-player card-based board game brawler. See **[MADMAX_GAME_GUIDE.md](MADMAX_GAME_GUIDE.md)**
for how to open it in Roblox Studio and how the game works. Code lives in `src/`.
