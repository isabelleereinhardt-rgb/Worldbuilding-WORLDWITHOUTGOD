    Edit mode

    While editing: click a marker → ✎ Edit its name, type and description; drag markers to move them; click empty map to add a new place; the title and About text become editable too. Changes are saved in this browser; use the download button to get an updated places.js you can commit to the site.

    Distance tracker ▾

    Type two places, or click near two markers on the map and use Measure ▸ start / ▸ end. Shows overland distance and travel time; if both sit on the coast a sea route and sailing time appear too, and inland places are flagged as not reachable by ship.
